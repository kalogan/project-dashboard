How I structure work with coding agents so the output is trustworthy by default
rather than by inspection.

## The Loop

1. State the task as a crisp, verifiable outcome.
2. Let the agent plan before it edits.
3. Run the build and tests; treat green as the only definition of done.

## Context Discipline

Keep the agent's context lean — the relevant files and the contract, nothing
more. Noise in, noise out.
